Guide: Custom Color Roles for Your Discord Server Short card-style summary for quick reading.

Color Roles Feature

Lets server owners create custom color roles for members to choose, improving visual identity and engagement.

Getting Started

Open the dashboard, choose your server, and enter the color module.

Configuration

Create roles named 1, 2, 3, 4 (numeric only). The bot auto-detects them as color choices.

List Title

Set the Color List Title to match your server brand.

Shape

Choose circle or square icons from the settings panel.

Background

Use transparent or custom-image background (recommended under 3MB).

Preset Sets

Pick a preset card and confirm to apply it.

Tips

Users should select one color role, and the bot role must be above color roles in server hierarchy.

Apply color set

Applying this set will automatically create roles matching the selected colors.
