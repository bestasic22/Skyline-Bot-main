1. ข้อมูลที่เราอาจเก็บ (Data We Collect)

เช่น Guild ID, Channel ID, Role ID, User ID และข้อมูลที่จำเป็นต่อการทำงานของคำสั่งและโมดูลต่างๆ

ข้อมูลการตั้งค่า

ข้อมูลบันทึกการทำงาน

เช่น log เหตุการณ์สำคัญ, ข้อมูลข้อผิดพลาด และบันทึกที่จำเป็นต่อความปลอดภัยและการซัพพอร์ต

เราจะเก็บเฉพาะข้อมูลที่จำเป็นต่อการให้บริการ ไม่เก็บข้อมูลเกินความจำเป็นโดยไม่มีเหตุผลทางระบบ

2. วัตถุประสงค์ในการใช้ข้อมูล (Purpose of Use)

  • เพื่อให้ฟีเจอร์ของบอททำงานได้ถูกต้องตามการตั้งค่าแต่ละเซิร์ฟเวอร์
  • เพื่อปรับปรุงประสิทธิภาพ ความเสถียร และประสบการณ์การใช้งานของระบบ
  • เพื่อป้องกันการใช้งานที่ผิดปกติ การโจมตี และพฤติกรรมที่เสี่ยงต่อความปลอดภัย
  • เพื่อช่วยตรวจสอบปัญหาเชิงเทคนิคและให้การซัพพอร์ตผู้ใช้งาน

3. การจัดเก็บและความปลอดภัยของข้อมูล (Storage & Security)

  • มีมาตรการที่เหมาะสมเพื่อป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต
  • จำกัดการเข้าถึงข้อมูลเฉพาะส่วนที่จำเป็นต่อการดูแลระบบและการซัพพอร์ต
  • ข้อมูลบางส่วนอาจถูกเก็บตามระยะเวลาที่จำเป็นต่อการให้บริการและตรวจสอบความถูกต้องของระบบ

4. การเปิดเผยข้อมูลต่อบุคคลที่สาม (Third-party Disclosure)

  • เราไม่มีนโยบายขายข้อมูลส่วนบุคคลของผู้ใช้งาน
  • อาจมีการส่งต่อข้อมูลที่จำเป็นไปยังผู้ให้บริการภายนอกเฉพาะกรณีที่เกี่ยวข้องกับการทำงานของระบบ (เช่น Discord API หรือผู้ให้บริการชำระเงิน)

5. สิทธิของผู้ใช้งานและผู้ดูแลเซิร์ฟเวอร์ (Your Rights)

  • ผู้ดูแลเซิร์ฟเวอร์สามารถปรับเปลี่ยนการตั้งค่าระบบที่เกี่ยวข้องกับข้อมูลได้ผ่าน Dashboard
